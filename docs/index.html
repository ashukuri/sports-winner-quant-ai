🛠️ 年次メンテナンス手順 & 性能劣化防止プロトコル

本システムは動的特徴量エンジンにより日々の再学習は不要ですが、毎年8月〜9月（新シーズン開幕前）に1回だけ定期メンテナンスを行うことを推奨しています。

Step 1: 新シーズン分の試合データ追加

過去1年間の全公式戦データを収集し、特徴量データセットを更新します。

python scripts/update_annual_dataset.py

Step 2: モデルの年次定期再学習

過学習を防ぐ固定アーキテクチャにて、最新データを加えてパラメータを定期更新します。

python scripts/retrain_models.py

Step 3: 【最重要】性能劣化防止ゲート（品質検査）の実行

新モデルが旧モデルと同等以上の性能（Log Loss $\le$ 2.59, 勝敗的中率 $\ge$ 70%）を維持しているか自動判定します。基準を満たさない場合は自動で旧モデルにロールバックされます。

python scripts/verify_maintenance.py

Step 4: GitHub Pages への自動デプロイ

Web用モデルデータを更新し、GitHubへプッシュするとWebダッシュボードが自動更新されます。

python scripts/export_web_model.py
git commit -am "Annual Maintenance: Updated models for 2027 season"
git push origin main
