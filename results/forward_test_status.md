## 3. 次回以降の自動記録・精算プロトコル

今後、継続的にデータを蓄積するための標準運用手順（SOP）：

### Step 1: 次回対象試合の取得と登録
- 楽天toto / WINNER公式サイトのスケジュールAPIまたは画面を走査。
- 販売開始された試合を `data/verified_fixtures.csv` に自動追記。

### Step 2: 締切60分前のオッズ取得と予測推論
- 評価実行スクリプト:
  ```bash
  python src/forward/run_forward_pipeline.py --mode predict
  ```
- オッズ取得方式:
  - 自動HTTP取得（規約遵守）または手動インポートCLI（`src/odds/import_manual_odds_cli.py`）。
- 予測確率・表示倍率・EV・購入判断を `data/forward_predictions.csv` および `data/forward_transactions.csv` に暗号ハッシュ署名付きで固定保存。

### Step 3: 試合終了後の公式精算
- 試合終了翌朝（JST 09:00）に自動精算スクリプトを実行:
  ```bash
  python src/forward/run_forward_pipeline.py --mode settle
  ```
- 公式当せん番号および正式な1口当たり払戻金を取得し、`data/settlements.csv` を更新。
- 的中・不的中、純損益、残高、累積ROIを更新し、`results/roi_summary.csv` を自動再生成。

以上のシステム構築により、未来のすべてのWINNER対象試合に対して一切の事後改ざんや未来情報混入を排除したフォワードテストを継続運用できる体制が整った。
